# Recibos Alquileres

Página estática: elegís departamento, mes, cargás alquiler y servicios, y descargás el recibo en PDF.
Sin build ni dependencias de servidor (jsPDF viene en `vendor/`).

Para cambiar inquilinos o sumar departamentos, editá la lista `DEPTOS` al inicio del script en `index.html`.

## Deploy en Vercel
Importá el repo en Vercel con el preset "Other". No hace falta comando de build ni carpeta de salida.
